# 🪐 Интерактивная 2D-симуляция Солнечной системы

Добро пожаловать в космос! 🚀 Это интерактивное приложение, написанное на Python, которое позволяет вам почувствовать себя властелином времени и пространства. Наблюдайте за грациозным танцем планет вокруг Солнца в режиме реального времени (или ускоренном, если вам надоело ждать год на Земле).

Проект создан с использованием `tkinter` для графики и `Pillow` для работы с изображениями. Это отличный способ совместить изучение программирования, астрономии и насладиться красивой анимацией.

## ✨ Ключевые возможности (Фичи)

*   **🌍 Реалистичное движение:** Планеты вращаются с разными скоростями, приближенными к их реальным орбитальным периодам. Никакой магии, только физика (ну, почти).
*   **🌕 Луна - спутник Земли:** Наша верная соседка не забыта и послушно крутится вокруг голубой планеты.
*   **👆 Интерактивность:** Кликните по любому небесному телу (Солнцу, планете или Луне), чтобы мгновенно получить "досье": название, радиус орбиты, диаметр и текущую скорость вращения. Идеально для школьников и просто любопытных!
*   **⏱️ Управление временем:** Хотите, чтобы Юпитер сделал круг быстрее? Просто покрутите ползунок **Скорости**! Можно замедлить время для медитации или ускорить, чтобы быстро увидеть парад планет.
*   **🔍 Масштабирование:** Дальние планеты (Уран, Нептун) кажутся крошечными? Используйте ползунок **Масштаба**, чтобы рассмотреть их поближе, или отдалитесь, чтобы оценить общую картину.
*   **🖼️ Кастомные текстуры:** Если положить красивые PNG-картинки в папку `images`, программа будет использовать их вместо скучных цветных кружочков. Красота требует жертв (места на диске)!
*   **↺ Сброс вида:** Нажал не туда и потерял планеты? Кнопка **"Сброс вида"** вернет всё в норму.

## 🛠️ Технологии

*   **Язык:** Python 3.6+
*   **GUI:** Tkinter (родной для Python)
*   **Графика:** Pillow (PIL) для загрузки и обработки изображений планет
*   **Математика:** Встроенный модуль `math` (куда же без синусов и косинусов)

## ⚙️ Установка и запуск

Следуйте этим простым шагам, чтобы запустить вселенную на своем компьютере.

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/yourusername/solar-system-simulation.git
    cd solar-system-simulation
2. Установите зависимость (Pillow):
Tkinter уже должен быть установлен вместе с Python. Устанавливаем только то, чего не хватает.

```bash
pip install Pillow
```
3. Добавьте изображения (по желанию, но с ними лучше):

Создайте в папке проекта папку с именем images.

Поместите туда PNG-изображения. Программа будет искать файлы со строго определенными именами (регистр важен!):
```sun.png``` ,```mercury.png```, ```venus.png```, ```earth.png```, ```mars.png```, ```jupiter.png```, ```saturn.png```, ```uranus.png```, ```neptune.png```, ```pluto.png``` , ```moon.png```.

Совет: Используйте изображения с прозрачным фоном, чтобы они красиво смотрелись на черном фоне космоса.

4. Запустите симуляцию!

```bash
python sgshsh.py
```
(Не забудьте переименовать файл, если он у вас называется иначе)

🎮 Как играть (управление)
● ▶️ Запустить анимацию: Поехали!

● ⏸️ Пауза: Остановить мгновение (оно и так прекрасно).

● ↺ Сбросить углы: Вернуть все планеты на стартовые позиции (как в момент Большого взрыва, только для этого симулятора).

● Скорость (Ползунок): Регулировка времени. От 0% (стоп-кадр) до 200% (все бегут, как наскипидаренные).

● Масштаб (Ползунок): Приближение и отдаление. От 0.2x (обзорный план) до 3.0x (можно разглядеть Большое Красное Пятно на Юпитере).

● Сброс вида: Сбрасывает масштаб на 1.0x и скорость на 100%.

● Клик по объекту: Откроет модальное окно с характеристиками планеты.
